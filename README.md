# SomeBanksIcons

Иконки (логотипы) 100 крупнейших банков России по активам нетто (МСФО).

## Структура

```
├── light/
│   ├── svg/   ← логотипы светлой темы (SVG)
│   └── png/   ← логотипы светлой темы (PNG)
├── dark/
│   ├── svg/   ← логотипы тёмной темы (SVG)
│   └── png/   ← логотипы тёмной темы (PNG)
├── banks.json ← метаданные банков
└── README.md
```

Каждый банк идентифицируется lowercase-ID из `banks.json`. Файлы логотипов называются по ID банка:
- `light/svg/sberbank.svg`
- `light/png/sberbank.png`
- `dark/svg/sberbank.svg`
- `dark/png/sberbank.png`
